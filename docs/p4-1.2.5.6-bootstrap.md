# P4-1.2.5.6 — Persistent Bootstrap Metadata and unified physical extents

BMPOOL03 is a separately versioned dynamic Pool format with an 8MiB Bootstrap reservation:
- Two 4KiB Bootstrap records at offsets 0 and 4KiB.
- Two alternating 2MiB Extent Map slots.
- Two 4KiB Bootstrap WAL pages after the map slots.
- Remaining reserved bytes are checked for zero at format time and held for format growth.

The record contains Pool UUID, generation, actual device bytes, Bootstrap bytes, total Metadata bytes, Extent Map root offset/length/generation, logical sector size, fenced OwnerEpoch and CRC32C. The extent map must cover the full device without gaps or overlaps.

The same physical allocator classifies Metadata, Data and Free extents. OpenExtentView returns bounded views for individual extents; OpenDataView concatenates fragmented Data extents into one logical data device while keeping all I/O on the same parent LUN.

The formatter refuses BMPOOL02 markers and any non-zero byte in the reserved Bootstrap area. BMPOOL02 is not rewritten or migrated by this implementation.
