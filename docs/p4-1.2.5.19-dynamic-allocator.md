# P4-1.2.5.19 — Dynamic DataView and PoolAllocator

Adds a DynamicSharedCommitter that reopens the correct geometry-sized AG
journal while holding a distributed SAN WAL resource. It implements the
metastore ClusterSafeCommitter contract, allowing PersistentArena/B+Tree root
publication to use the BMPOOL03 journal without using BMPOOL02 Superblock
geometry.

The next integration step binds the allocator's physical block IDs directly
to DataView-relative 4MiB block numbers. No DataStartSector offset is added:
the bitmap bit index, Mapping physical block ID and DataView byte offset all
share the same zero-based DataView coordinate system.
