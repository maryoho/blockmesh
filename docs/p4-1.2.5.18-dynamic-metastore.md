# P4-1.2.5.18 — MetadataView and Persistent Volume Metadata

Adds the BMPOOL03 BMDVOL03 Volume Descriptor pair in the dynamic Node Table
region and `OpenDynamicPoolVolume` over a logical MetadataView. The
existing metastore Store, PersistentArena, page codec and lifecycle WAL
interface can now operate on MetadataView-relative page IDs without writing
the BMPOOL03 superblocks at logical pages 0/1.

The descriptor stores Volume identity, AG, owner epoch, mapping root offset,
Arena range, root page, mapping sequence and lifecycle range. Descriptor root
publication is the final after-image in the metadata transaction. Dynamic
Bitmap pages are admitted as fixed-LBA transaction extras; Volume COW pages
and lifecycle pages remain governed by PersistentArena reservations.

This is an initial BMPOOL03 metadata-store integration. It does not yet provide
dynamic per-Volume Reader Table / Owner Record slot partitioning, nor a
multi-Volume reserved-region allocator. Those are explicit follow-up work;
do not infer BMPOOL02 slot compatibility from the shared descriptor fields.
