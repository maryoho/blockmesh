# P4-1.2.5.13 — BMPOOL03 Dynamic Superblock

BMPOOL03 now has a separate 4KiB DynamicSuperblock codec and magic/version.
It persists the logical DataView size, MetadataView size, view generation,
AG geometry (including LastAGBlocks), bitmap dimensions and all metadata
region offsets. Decode validates CRC32C and recomputes the complete geometry
from its persisted inputs; a valid CRC cannot make inconsistent offsets valid.

The codec is intentionally separate from the BMPOOL02 Superblock and does not
alter NewSuperblock, BMPOOL02 magic, or the legacy on-disk layout. The bootstrap
Extent Map remains authoritative for physical parent-LUN placement; the dynamic
superblock describes the logical views built from one Extent Map generation.

This stage provides encoding/decoding only. Dual-copy publication, WAL-protected
superblock switching, runtime open, and dynamic allocator integration follow.
