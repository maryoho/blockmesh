# P4-1.2.5.14 — Dynamic AG Bitmap Allocation Planner

Adds PlanDynamicBitmapAllocation for the BMPOOL03 dynamic superblock. The
planner reads the AG descriptor and padded bitmap from the MetadataView address
space, validates the bitmap CRC, finds a contiguous run only within the AG's
valid block count, and emits descriptor plus changed bitmap-page after-images.

The physical block number is DataView-relative:
AGStartBlock + local bitmap bit. For the final partial AG, the planner never
scans or allocates padding bits beyond LastAGBlocks.

This is a planning primitive only. It does not commit a WAL transaction, zero
the DataView, or publish B+Tree mappings. BMPOOL02 PlanBitmapAllocation is
unchanged. Dynamic WAL routing and PoolAllocator integration remain subsequent
work.
